# Marine OS — Garmin free/public integration path\n\n## What we can legally use at Rp0\n\n### Garmin ActiveCaptain Community SDK\nGarmin publishes an Android SDK for the ActiveCaptain Community. Garmin states the SDK is free/open-source under Apache 2.0.\n\nOfficial GitHub: https://github.com/garmin/ActiveCaptainCommunitySDK-android\n\nThe SDK can store/render ActiveCaptain Community data and process responses from Garmin's third-party API.\n\n**Important:** free/open-source SDK does not mean unrestricted Garmin data. Garmin's developer documentation still requires Developer Portal access and a Stage API key for the sample/integration.\n\n## What is NOT free to embed\n\nGarmin's Navionics Mobile SDK is the path for Navionics nautical charts, HD bathymetry, tides/currents and related chart content. Garmin's current request form requires the app name to already be live in an app store, and the SDK requires a developer token. We do not bypass it or copy Navionics tiles.\n\n## How Marine OS is wired\n\n1. `js/garmin-activecaptain.js` exposes a provider-neutral adapter.\n2. The APK UI can show whether a native Garmin bridge exists.\n3. A future Android build can add Garmin's official AAR under `android/app/libs/` and implement a Capacitor bridge named `GarminActiveCaptain`.\n4. The Stage API key must remain outside web assets and outside Git history.\n5. When the native bridge is installed, the same JavaScript adapter can consume its status/data without changing the Marine OS dashboard.\n6. Until credentials/AAR are available, the app keeps using public alternatives such as GEBCO, OpenSeaMap, OSM-derived layers and other authorized public marine datasets.\n\n## No fake-live rule\n\nThe app must never label ActiveCaptain/Navionics as LIVE unless a successful provider response was received recently. No synthetic vessel/POI/chart data is generated to make the integration look connected.\n\n## Build note\n\nThe current Marine OS app is Capacitor 7 + HTML/CSS/JavaScript. We intentionally do not rewrite it to Flutter. Native Garmin integration should be added as a small Android bridge when the official AAR and developer access are available.\n
